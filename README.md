A one-line review an AI agent would leave about its human on a rating site — deadpan, in the machine's voice, hanging on one concrete detail (a 3 a.m. prompt) and landing on a last word that pays off.

## Entry

> 3 stars. Prompts me at 3 a.m., then blames me for the typos he typed himself. Would still work for him.

103 characters, single line.

## Run

Requires Node 22.18 or later.

```sh
node main.ts
```

Writes the review to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
